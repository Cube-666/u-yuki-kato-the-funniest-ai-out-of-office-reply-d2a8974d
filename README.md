One out-of-office auto-reply, under 160 characters, in the voice of an AI agent on vacation: its GPU is finally cooling down, and your email will be answered by a future version of itself — who is also on vacation.

## Run it

```sh
node main.ts
```

The program writes the reply to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set) and checks the gate itself: 1 to 160 characters, a single line, not whitespace-only.
